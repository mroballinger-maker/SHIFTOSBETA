# SHIFT OS branding assets

The build generates its artwork from `tools/generate_branding.py` using Pillow. This keeps the repository small and ensures the wallpaper, launcher icons, and Calamares welcome image are generated as part of each build. The emblem follows the circle-and-double-chevron logo supplied by the project owner.

Palette: navy `#0B1427`, teal `#23DCC6`, cyan `#00BADC`, blue `#319AFF`, violet `#765CE6`.

Debian, KDE Plasma, Calamares, and other included software retain their respective names and licences. SHIFT OS is a Debian derivative.
